# FeedHacker — KNOWN_ISSUES.md

The bug ledger / audit trail. Every real bug is recorded here with its **root cause → fix (PR)
→ the regression test that locks it**. This turns a one-off fix into a permanent guardrail, and
(with [`best_practices.md`](best_practices.md)) closes the review loop so a class of bug can't
recur silently. The **Found by** column records where each bug actually came from — worth keeping
now that there's no bot reviewer (see [`REVIEWERS_STATUS.md`](REVIEWERS_STATUS.md)) and CI plus
self-review are the whole net.

**Status:** 🔴 open · 🟡 mitigated / accepted · ✅ fixed + tested

## Recurring classes (watch these hardest)

- **Extension-context invalidation** — orphaned content scripts after a Chrome update/reload
  (`chrome-extension://invalid/`). Guard `chrome.*`, tear down cleanly. (best_practices §6)
- **Concurrent `chrome.storage` writers** — two async paths, last-write-wins, dropped data.
  One writer per key. (§7)
- **Re-scoring collapsed stubs from live DOM text** instead of stored features. (§8)
- **Learner overwriting a user control** — bind the control to the value the tuner honors. (§9)
- **Injected controls losing listeners on React re-render** — delegate clicks. (§10)
- **False green / dishonest status or counts.** (§4, §5)
- **Health/heartbeat alarms that can't tell "empty" from "broken"** — fire on positive evidence of
  failure, suppress during loading/paging. (§31)
- **Store listing vs. shipped package drift** — the listing's assets/copy publish separately from
  the uploaded package, so the store page can advertise something no install has. (§33)
- **Reading DOM state after we've hidden the element** — a collapsed post's `innerText` is our own
  stub, so anything derived at click time (author, URL, text) is wrong. Capture while visible,
  stash on the element. (§36; the scoring half is §8)
- **A collapsed/aggregate view silently dropping the actions it stands in for.** (§37)
- **Per-DOM-node state on a framework-rendered page.** LinkedIn replaces feed nodes, so anything
  we hang on the element (a "scanned" flag, a user's choice) dies with it and the work is redone
  forever. Key on the content's own identity. (§46)
- **Scoring the same evidence twice**, or scoring a *style* rule as *forensic* evidence — how
  ordinary human writing ends up classified as AI slop. (§39, §40)
- **A "target fraction" implemented as a quota rather than a ceiling** — the filter removes the
  same share of the feed however clean it is. (§42)
