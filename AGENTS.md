# AGENTS.md — read this before any work

## Every AI agent reads this file first

`AGENTS.md` is the shared entry point for every AI agent in this repository. Each tool also has its own file,
and every one of those points back here. The rules are the same for all of them.

| agent | its own file | what that file does |
|---|---|---|
| OpenAI Codex / ChatGPT | `AGENTS.md` (this file) | read natively |
| Claude Code | [`CLAUDE.md`](CLAUDE.md) | imports this file with `@AGENTS.md`, then holds the long-form operating notes |
| Gemini (CLI / Code Assist) | [`GEMINI.md`](GEMINI.md), [`.gemini/settings.json`](.gemini/settings.json) | loads this file directly |
| Grok (xAI) | [`GROK.md`](GROK.md), [`.grok/GROK.md`](.grok/GROK.md) | points here (Grok Build also reads this file directly) |
| GitHub Copilot | [`.github/copilot-instructions.md`](.github/copilot-instructions.md) | points here; the coding agent also reads this file directly |

The same files sit in the same places in every fleet repo, so an agent in the browser or in an app reaches this file the same way. `python3 tools/agent_pointers.py` fails on any drift (`--fleet <other checkouts>` compares repos). A new agent gets a pointer file of its own, and a row in this table, in every fleet repo in the same change.


This is the entry point for every coding agent. Claude Code's long-form notes are in [`CLAUDE.md`](CLAUDE.md); read it next, then [`best_practices.md`](best_practices.md), [`KNOWN_ISSUES.md`](KNOWN_ISSUES.md) and [`SESSION-STATE.md`](SESSION-STATE.md). The rules are the same for every agent.
